# sergio-resume-pages

Sitio estático listo para **GitHub Pages** con el CV de Sergio Estrada Valenzuela.

## Archivos
- `index.html` — página principal del CV
- `styles.css` — estilos del sitio
- `resume.md` — versión fuente en Markdown del CV
- `.nojekyll` — evita procesamiento innecesario de Jekyll en GitHub Pages

## Publicación en GitHub Pages
Cuando me compartas la URL del repositorio de GitHub, puedo dejarlo listo para subir ahí.

Si lo quieres publicar manualmente:
1. Sube estos archivos a la raíz del repositorio.
2. En GitHub ve a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/ (root)`.
5. Guarda los cambios.

GitHub Pages servirá `index.html` automáticamente.
